# 你们这些还魂尸 / All You Zombies

一部基于罗伯特·海因莱因（Robert A. Heinlein）同名短篇小说的**原创同人改编**视觉小说。

An original **fan-adaptation** visual novel based on Robert A. Heinlein's short story of the same name.

---

## 简介 / About

深夜的酒吧，打烊之前。你扮演酒保，倾听一位陌生人讲述他不可思议的一生——一个关于时间、身份与孤独的闭环。通过你的对话选择，你将决定如何理解这个故事，而你的态度，会导向不同的结局。

A late-night bar, just before closing. You play the bartender, listening to a stranger tell the story of his impossible life — a closed loop about time, identity, and loneliness. Through your dialogue choices, you decide how to understand this story, and your attitude leads to different endings.

## 特性 / Features

- **对话探索型叙事**：自由选择询问的话题，触发对应闪回 / Dialogue-driven exploration with branching flashbacks
- **三轴情感系统**：愤恨 / 释然 / 困惑，导向 3 种结局 + 1 个隐藏结局 / A three-axis emotion system (Resentment / Acceptance / Bewilderment) leading to 3 endings + 1 hidden ending
- **中英双语**：可在设置中随时切换 / Bilingual (Chinese / English), switchable in Preferences
- **写实油画风美术**，按时代分层调色 / Realistic oil-painting art with era-based color grading
- **七处隐藏线索**，集齐解锁彩蛋 / Seven hidden clues to collect

## 运行 / How to Run

需要 [Ren'Py 8.x](https://www.renpy.org/) 运行时。

Requires the [Ren'Py 8.x](https://www.renpy.org/) runtime.

```

renpy.exe /path/to/all_you_zombies
```
