## 2. 选择路径覆盖（防死局）✓

### 2.1 话题解锁链
```
T1(初始) T2(初始) → T3(需T2) → T4(需T3 + trust≥3) → T5(需T4) → 全完成→第二幕
```
- 所有话题最终可达，无孤立节点。
- **信任度防死局验证**：T4需 trust≥3。信任来源——序章选择(最多+3)、T1"她不是坏的"(+2)、以及话题枢纽的"沉默续酒"选项(+1，**可重复**)。因此即使玩家一路选非共情选项，也能通过反复"沉默续酒"攒够信任，**不会卡死**。✓

### 2.2 结局可达性
- 三轴情感值由约25-35个选择点累积，全程无强制单一走向。
- 隐藏结局(三轴均≥12)理论可达：需玩家在各幕均衡选择愤恨/释然/困惑选项。
- `determine_ending()` 逻辑：隐藏结局优先判定，否则取主导轴。无平局歧义（max取唯一主导；若两轴并列取max第一个，行为确定）。✓

### 2.3 跳转完整性
- 所有 `jump` 目标标签均存在：`act1_hub` / `act2_offer` / `act3_jump` / `ending_hub` / `credits` / 各 `topic_*` / 各 `ending_*`。✓
- 无悬空跳转、无未定义标签。
